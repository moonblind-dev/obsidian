### **1.2 AS-IS 분석 (Current State Analysis)**

#### **A. 운영 현황 진단 프레임워크**

**4M 분석**

|영역|진단 항목|평가 척도|문제 사례|
|:--|:--|:--|:--|
|**Man**|인력 구성, 스킬, 근무 형태|정규/임시 비율, 이직률|계절工 의존, 숙련도 불균형|
|**Machine**|설비 가동률, 노후화|OEE(설비종합효율)|지게차 과잉/부족, 컨베이어 정지|
|**Material**|재고 회전, 공간 활용|공간 활용률, 재고일수|사은품 적치, 공간 부족|
|**Method**|프로세스 표준화, IT 활용|SOP 준수율, 디지털화율|수기 작업, 이중 입력|

**물류 비용 분석 (Cost-to-Serve)**

```plain
총 물류비 = 입고비(10%) + 보관비(25%) + 피킹/패킹비(35%) + 출고비(20%) + 관리비(10%)

단위 비용 지표:
- Case당 입고 비용
- Location당 보관 비용  
- Line당 피킹 비용
- Order당 출고 비용
```

#### **B. 병목 구간 식별 (Bottleneck Analysis)**

**VSM(Value Stream Mapping) 활용**

```plain
[현재 상태 프로세스맵]
입하 → (대기 2H) → 검수 → (이동 30분) → 적치 → (보관 15일) → 
보충 → (피킹 20분/Line) → 검품 → (패킹 5분) → (대기 4H) → 출하

LT: 15일 6시간 / 가치창출 시간: 25분 → 비가율 99.7%
```

**병목 우선순위 Matrix**

| 심각도 | 발생 빈도 | 개선 우선순위 | 예시       |
| :-- | :---- | :------ | :------- |
| 높음  | 높음    | **1순위** | 출고 도크 부족 |
| 높음  | 낮음    | 2순위     | 설비 고장    |
| 낮음  | 높음    | 3순위     | 경로 중복    |
| 낮음  | 낮음    | 4순위     | 사소한 대기   |

### **1.3 타당성 검토 (Feasibility Study)**

#### **A. 투자 비용 산정 (Capex)**

|투자 항목|세부 내용|산정 기준|비중|
|:--|:--|:--|:--|
|**토지/건물**|매입 또는 임대|㎡당 단가 × 면적|40~60%|
|**랙/선반**|선택적, 드라이브인, 자동화|Location당 단가|10~15%|
|**설비**|지게차, 컨베이어, 분류기|대당 단가 × 수량|15~25%|
|**자동화**|AGV, 로봇, AS/RS|시스템 단위 견적|10~30%|
|**IT 시스템**|WMS, WCS, 바코드/RFID|라이선스 + 커스터마이징|5~10%|
|**기타**|소방, 보안, 사무 가구|기준 설비비의 5~10%|3~5%|

**예비 견적 산출 예시**

```plain
[시나리오별 투자 규모 - 연면적 10,000㎡ 기준]

시나리오 A (수동): 50억원
- 토지/건물 임대, 핸드리프트, RF 시스템

시나리오 B (반자동): 80억원  
- 자동 분류기, 컨베이어, WMS 고급 모듈

시나리오 C (전자동): 150억원
- AS/RS, 로봇 피킹, AI 예측 시스템
```

#### **B. 운영 비용 예측 (Opex)**

|비용 항목|산정 방식|연간 증감 요인|
|:--|:--|:--|
|인건비|월평균 인건비 × 인원수 × 12|최저임금 인상, 생산성 향상|
|임차료|㎡당 임대료 × 면적 × 12|계약 갱신 시 인상률|
|유틸리티|전기/가스/수도 요금|에너지 효율 설비, 요금 인상|
|설비 유지보수|투자비의 3~5%|노후화에 따른 증가|
|IT 유지보수|라이선스비 + 유지보수 15~20%|기능 추가, 업그레이드|
|포장재/소모품|건당 단가 × 물동량|원자재 가격 변동|

#### **C. 경제성 분석 (ROI/NPV/IRR)**

**핵심 지표 계산**

```plain
투자회수기간(PP) = 초기투자비 / 연간 순현금흐름

순현재가치(NPV) = Σ(미래현금흐름/(1+할인율)^n) - 초기투자비

내부수익률(IRR): NPV=0이 되는 할인율
```

**민감도 분석 (Sensitivity Analysis)**

|변수|낙관적|기본|비관적|NPV 변화|
|:--|:--|:--|:--|:--|
|물동량 성장률|+20%|기준|-20%|±30%|
|건설비 상승률|+5%|+10%|+20%|∓15%|
|인건비 상승률|+3%/년|+5%/년|+8%/년|∓20%|

|리스크 유형|구체적 사례|발생 확률|영향도|대응 전략|
|:--|:--|:--|:--|:--|
